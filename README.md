# Cyberpunk 2077 - Night City: Neón y Cromo

Landing page temática desarrollada como parte de las actividades prácticas para el curso de Ingienería en Software

## Descripción del Proyecto
Este proyecto consiste en una página web estática de una sola sección centrada en la exploración de Night City, sus distritos y la cruda realidad de su atmósfera distópica. Su objetivo principal es aplicar los fundamentos de la estructura HTML semántica y el diseño moderno mediante hojas de estilos en cascada (CSS).

## Estructura del Proyecto
```text
├── index.html        # Archivo principal con la estructura HTML
├── style.css         # Hoja de estilos con la paleta visual y diseño de tarjetas
└── README.md         # Documentación del proyecto
```
