# Cyberpunk 2077 - Night City: Neón y Cromo

Landing page temática desarrollada como parte de las actividades prácticas para el curso de Ingienería en Software

## Descripción del Proyecto
Este proyecto consiste en una plataforma web interactiva inspirada en el universo distópico de Cyberpunk 2077, enfocada en la exploración temática de Night City, sus distritos y la cruda atmósfera que define a sus leyendas urbana. Su objetivo principal es estructurar un sitio dinámico utilizando HTML y diseño CSS moderno, enriquecido mediante manipulación con JavaScript para ofrecer una experiencia de usuario fluida e inmersiva.

## Estructura del Proyecto
```text
├── index.html        # Archivo principal con la estructura HTML
├── style.css         # Hoja de estilos con la paleta visual y diseño de tarjetas
├── app.js            # Elementos interactivos de la página
└── README.md         # Documentación del proyecto
```
